# 风格方向样例

第一次有界面时，先出 2–3 个风格方向让产品负责人选，选定的那个再展开成 `docs/设计规范.md`。

## 每个方向写什么

| 项 | 写法 |
| --- | --- |
| 一句话 | 这个方向给人什么感觉、参照什么（"像备忘录一样安静的纸面"） |
| 适合 | 什么产品、什么用户 |
| 颜色 | 主色、背景、卡片底、正文、次要文字的色值；要做深色模式的同时给深色值 |
| 字体和字号 | 字体、正文字号和行高、标题级数 |
| 圆角 | 分几档、各多大 |
| 层次 | 靠底色深浅、细线还是阴影区分区域 |
| 按钮和卡片 | 形状（胶囊 / 圆角矩形 / 直角）、主次按钮长什么样 |
| 动效性格 | 克制还是有弹性，时长大概多少，有没有特色动效 |
| 代价 | 这个方向难在哪、哪里容易做走样 |

能做的话，每个方向配一张预览：拿产品里同一个真实页面（首页或最常用的页面），用不同方向各画一版，放在一起给产品负责人看。用真实文案，不用占位文字。

选定以后，用 [界面底线.md](界面底线.md) 过一遍再写进设计规范。

## 样例 A：备忘录风（Paperwind 的实际做法）

Paperwind 是一个 Windows 上的 Markdown 编辑器，整体参照苹果"备忘录"。下面摘自它的设计说明，可以当作一份写得好的设计规范来参考。

- **一句话**：内容是主角，界面像一张安静的纸
- **适合**：阅读、写作、笔记、工具类，用户长时间盯着内容看的产品
- **版式**：正文 17px、1.6 倍行距，内容最宽 720px 居中
- **层次**：靠背景深浅、半透明材质和柔和阴影区分区域，几乎不用分隔线和边框；标题栏和工具栏合成一条，侧栏与它融为一体
- **圆角**：按尺寸分五档 6 / 12 / 16 / 20 / 28；嵌套元素用同心圆角，内外弧线平行；格式栏、浮动菜单、提示气泡、主按钮都是胶囊形
- **颜色**：只有一个主色（备忘录的暖黄），只出现在光标、勾选、按下的按钮、引用竖线、列表圆点上，其余全是中性灰（具体色值以项目自己的设计规范为准）
- **细节**：段落样式面板里每一项按自己的字号预览；清单是圆形勾选框，勾上后文字变淡，不加删除线；表格只画横线；代码高亮用 Xcode 的配色
- **尊重平台**：窗口按钮保持 Windows 原生样子，不模仿 macOS；字体用 Segoe UI Variable / 微软雅黑；图标是圆头线条风格
- **尊重系统设置**：跟随深色模式；"减少动态效果"开启时所有动效改为淡入淡出；"透明效果"关闭时改为实色
- **动效性格**：自然、快、有物理感。浮动菜单和弹窗从 96% 大小带一点回弹弹出；按钮按下缩到 0.96 再回弹；特色动效是翻页时旧页碎成粒子飘散（约 1 秒）。动效播放时照样能操作
- **代价**：半透明材质只有 Windows 11 支持，要准备实色版本；粒子动效在大窗口、高分屏上可能掉帧

## 样例 B：克制编辑风（taste-skill 的审美）

来自 taste-skill（github.com/Leonxlnx/taste-skill，MIT 许可）的设计系统，原本用于官网，这里只取跟界面有关的部分。

- **一句话**：像一张印得很讲究的白纸，几乎全是黑白灰，只有一点点颜色
- **适合**：效率工具、金融、企业后台、数据类，用户要的是清楚和可信
- **颜色**：界面 90–95% 是中性色，只有一个强调色，在一屏里占比不到 3%，只用在主按钮、焦点、链接和状态上。示例配色"白纸蓝笔"：背景 #ffffff、卡片底 #f4f4f4、正文 #111111、次要文字 #6b6b6b、强调色 #1a4be0（上面的字 #ffffff）
- **字体和字号**：正文 16px，行高 1.5–1.8；标签 13px；字重只用 400 和 500；不用全大写
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
- **圆角**：三档任选一套，偏硬朗 4 / 6 / 8，默认 8 / 12 / 20，偏圆润 10 / 16 / 24
- **层次**：静止时不用阴影，卡片靠比背景深一档的底色加 1px 细线（正文色 8–14% 透明度）；只有能点的卡片在悬停时带一点很淡的阴影
- **按钮和卡片**：每屏一个实心主按钮，次按钮只有一种样式；不用渐变、斜切、发光的按钮；卡片内边距不小于 24px，卡片里不再套卡片，不用毛玻璃
- **动效性格**：克制、利落、不回弹。悬停 150ms、按下 90ms、面板展开 200ms；统一用缓出曲线 cubic-bezier(.2,.8,.2,1)；能点的卡片悬停上浮 2px，按下下沉 1px
- **代价**：做不好容易显得冷、空、像模板；它原本没有中文字体和小程序的规则，要自己补

## 第三个方向怎么出

按产品气质自己拟，和前两个拉开差距，让产品负责人有真正的选择。例如面向年轻用户的消费类产品，可以出一个"亲和圆润风"：大圆角、明亮的主色、插画或真实照片、按钮和反馈带一点弹性。照上面"每个方向写什么"的表填全，不要只写形容词。
