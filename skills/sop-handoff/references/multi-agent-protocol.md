# 多个 AI 工具协作约定（简化版）

适合"Claude 开发、WorkBuddy 验收、Trae 修复"这类同时用几个 AI 工具的情况。

## 角色

| 角色 | 职责 | 产出 |
| --- | --- | --- |
| 开发 | 理解需求、拆任务、写代码、出包 | 代码、更新说明、交接条目 |
| 验收 | 按验收清单测试、写报告、给结论 | 验收记录、证据 |
| 修复 | 读验收记录、定位、修复、通知重测 | 修复代码、修复说明 |

同一个任务里，开发和验收不能是同一个工具的同一个会话。

## 状态

在 `.agents/state.json` 里记当前状态：

```
规划中 → 开发中 → 验收中 → 通过
                    ↓ 不通过
                  修复中 → 验收中
```

## 交接消息

放在 `.agents/mailbox/`，文件名 `NNN-从谁-给谁.md`：

```markdown
- 编号：003
- 从：开发　给：验收
- 事由：M4 验收请求
- 内容：请按 docs/验收清单.md 第 12–14 节验收版本 3ac695f
- 附件：docs/交接文档.md、发布说明
- 时间：YYYY-MM-DD HH:MM
```

处理完在文件名后加 `_done`。

## 规矩

1. 每个工具开工前先读本约定、`docs/交接文档.md` 和自己角色的 skill
2. 开工前声明要改哪些文件；别人正在改的文件不碰
3. 验收结论只有三种：通过 / 有条件通过 / 不通过；没出包、没跑测试、没真机记录的，不能判"通过"
4. 收到别的工具的结论，先复核再采信
5. 所有结论最终都要写进 `docs/交接文档.md`，邮箱只是传话
